# FrorgBattle Alpha Version 4
Welcome to full rewrite number four of my turn based battle engine. This time, it'll be an actual engine - data driven, component based, actual UI (sorry frorgV3 😔), you name it. JUST ONE MORE REFACTOR I SWEAR 🙏

The following sections are the promises I'm making for what FrorgBattleV4 is to be.

## Uniquely custom abilities
So you know how you had a lot of freedom with frorgbattleV2 abilities? You know, you could make them do basically anything, and then use them in game to do that anything. Well my ahh decided that's not enough. Introducing:
#### Shards
Now, instead of launching an ability every turn, you link up several parts together to create one on the spot. You select the targeting, you select some buffs, then you select your favourite attacks and kablooey! Fully custom ability.

## JSON Support
Fully data driven! You can write any character, shard, effect, and maybe more using a JSON schema that I have yet to create. But eventually FrorgBattle API gonna go crazy ngl.

## Graphical User Interface
This was suppposed to come in FrorgV3, but I unfortunately got stuck refactoring abilities before I got to finish it. I've learned quite a bit, though, and now I can do it with a few less headaches than before. Point is - GUI !!! Very useful for something like this. Also, fully modular as well. You don't have to use my GUI implementation if you don't like it. Just make a mod for a custom UI. Wait, what's that?

## Modding support
Okay, I'm getting ahead of myself. This *is* planned, but in the future. It's a dateless "I will do it". It's a promise, but not a very soon-to-be one.
